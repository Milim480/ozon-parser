# Ozon Parser

Учебный парсер товарной ленты Ozon на Selenium и BeautifulSoup. Открывает страницу (главную или категорию с фильтрами), прокручивает бесконечную ленту, собирает карточки товаров и сохраняет их в CSV для дальнейшей аналитики.

## Что собирается

| Поле | Описание |
|---|---|
| `title` | название товара |
| `price` | текущая цена, ₽ |
| `old_price` | цена без скидки (пусто, если скидки нет) |
| `discount` | скидка в процентах (0, если скидки нет) |
| `rating` | рейтинг |
| `reviews` | число отзывов |
| `url` | ссылка на товар без трекинговых параметров |
| `round` | номер раунда прокрутки, на котором товар найден |
| `parsed_at` | дата и время запуска парсера |

Пустое значение означает «не удалось прочитать», а не ноль. В аналитике такие строки нужно исключать из расчётов по соответствующему полю.

## Установка

Нужны Python 3 (проект писался на 3.14) и установленный Google Chrome.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Программа спросит:

1. **Ссылка** — `https://ozon.ru` или любая категория с фильтрами, например `https://www.ozon.ru/category/umnye-chasy-15516/?currency_price=20000.000%3B50000.000&delivery=8`.
2. **Режим** — `1` собирать по количеству, `2` собирать по времени.
3. **Имя файла** — без `.csv`.

После открытия страницы у вас есть 10 секунд, чтобы вручную решить капчу, если она появилась.

**Режим 1 (по количеству).** Вводите, сколько товаров нужно. Парсер останавливается, когда набрал это число.

**Режим 2 (по времени).** Парсер 15 секунд собирает пробную порцию и замеряет скорость, затем показывает прикидку «за N секунд получится примерно K товаров». Вы подтверждаете, меняете время или переключаетесь на количество. Пробные товары не теряются: основной сбор продолжается с того же места.

В любом режиме сбор останавливается раньше, если три раунда подряд не появляется новых товаров (категория кончилась или страница зависла).

## Как это работает

```
main.py ──► browser.py ──► collectors.py ──► parsing.py ──► storage.py
 диалог     открыть Chrome   цикл сбора      разбор карточки  CSV и отчёт
```

1. `utils/browser.py` запускает Chrome через Selenium, маскирует его (`selenium-stealth`) и умеет прокручивать страницу.
2. `utils/collectors.py` содержит `collect_feed`. Ozon держит в HTML только окно примерно из 60 карточек и выбрасывает ушедшие вверх, поэтому страница разбирается **до** каждой прокрутки, а не один раз в конце. Дубли отсекаются по ссылке. Если в новом окне нет ни одной уже виденной карточки, выводится предупреждение: окна не пересеклись, возможны пропуски.
3. `utils/parsing.py` превращает HTML в дерево BeautifulSoup. Карточка ищется от ссылки `/product/` вверх до родителя с атрибутом `data-index`. Поля достаются по содержимому текста (`₽` значит цена, `%` значит скидка, слово «отзыв» значит число отзывов), а не по номерам элементов.
4. `utils/cleaning.py` оставляет в строке только цифры (`"1 299 ₽"` становится `1299`).
5. `utils/storage.py` пишет CSV (`utf-8-sig`, чтобы Excel правильно показал кириллицу) и печатает отчёт о том, сколько значений не прочиталось в каждом поле.

## Ограничения

- Парсер зависит от разметки Ozon: ссылки `/product/`, атрибут `data-index` у карточки и положение блока цен внутри карточки. Если Ozon что-то из этого изменит, соответствующую часть придётся поправить.
- Классы CSS на Ozon обфусцированы и часто меняются, поэтому парсер на них не опирается.
- Капчу нужно решать вручную в окне браузера.
- Парсер рассчитан на бесконечную ленту. Страницы с кнопками пагинации пока не поддерживаются. Если это нужно, напишите в Issues, и я постараюсь добавить.
- Прикидка в режиме «по времени» приблизительная: скорость зависит от категории, сети и состояния сайта, а категория может кончиться раньше срока.
- В `browser.py` платформа для `stealth` задана как `Linux x86_64`. На другой системе её стоит поменять.

## Дисклеймер

Проект учебный. Автоматизированный сбор данных может нарушать правила сайта, поэтому используйте его ответственно, с небольшими объёмами и без нагрузки на сервис.
